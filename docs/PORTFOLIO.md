## 30 秒ピッチ

> SpliTrip は、グループ旅行の割り勘を記録から精算まで一気通貫で扱う Web アプリです。  
> 出費の按分・リアルタイム同期に加え、債務を整理して送金回数を減らす精算プランを自動生成します。  
> Next.js と Supabase でフルスタック実装し、本番（splitrip.net）で運用しています。

## 面接で深掘りされやすいポイント

### 1. 精算アルゴリズム

**質問例:** どうやって送金回数を減らしている？

**答えの骨子:**

- 各メンバーのネット残差（支払 − 負担）を計算
- 債務者・債権者を金額順にマッチングするグリーディ法
- 実装: `src/lib/simplify-debts.ts`、テストあり

### 2. マルチユーザー・セキュリティ

**質問例:** 他グループのデータを見られないようにしている？

**答えの骨子:**

- Supabase RLS で `group_members` に所属する行のみ SELECT/INSERT 可能
- API でもメンバーシップを再検証
- エラーレスポンスに DB 内部情報を載せない方針

### 3. リアルタイム同期

**質問例:** 複数人が同時に編集したときどうなる？

**答えの骨子:**

- Supabase Realtime + SWR でキャッシュ更新
- 他ユーザーの変更をトースト通知

### 4. 国際化

**質問例:** 多言語対応の設計は？

**答えの骨子:**

- next-intl、辞書ファイルで文言を一元管理
- サーバー・クライアント両方で型安全な `t()` 関数
- ログイン後はユーザーの `preferred_language` を優先

### 5. 本番運用

**質問例:** 障害時・メンテ時はどうしている？

**答えの骨子:**

- メンテナンスモード（環境変数 + DB スケジュール）
- 公開ステータスページ + GitHub Actions による定期プローブ
- 管理画面でお知らせ・メンテ告知を DB 管理
